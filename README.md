# Prince Kumar Portfolio

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

## Folder structure
- index.html
- css/style.css
- js/script.js
- resume.pdf (add your own resume here)

## Before publishing
1. Replace `your-email@example.com`.
2. Replace GitHub and LinkedIn links.
3. Add your real project repository/demo links.
4. Put your resume PDF in the root folder as `resume.pdf`.
5. Optionally add a profile image.
